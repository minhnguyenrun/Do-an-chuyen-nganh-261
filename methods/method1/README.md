# Method 1: Document Layout Analysis & Segmentation

Thư mục này dành cho phương pháp nghiên cứu bố cục tài liệu **Method 1**.

## Cấu trúc thư mục
- `notebooks/`: Chứa các Jupyter Notebook thực nghiệm (EDA, Model training/inference, Evaluation).
  - [`method1_eda.ipynb`](notebooks/method1_eda.ipynb): Phân tích khám phá dữ liệu (EDA) trên 4,999 mẫu DocLayNet.
- `src/`: Chứa mã nguồn pipeline (dataset loader, model architecture, infer, post-processing).
- `weights/`: Chứa trọng số mô hình hoặc checkpoint.
- `report/`: Báo cáo, biểu đồ và kết quả đánh giá.
