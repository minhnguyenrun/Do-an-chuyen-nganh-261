## Chosen approach and alternatives

Use verified public V3 `order`/`polygon_points` with explicit missingness plus a frozen pretrained potion8M encoder and genuinely fitted native LightGBM head. Existing train is absent, but DocLayNet rows contain GT-aligned pdf_cells text and geometry. Acquire at most64 true-train pages without parquet shards; retain a grouped calibration holdout. PDF-cell fitting is the minimum viable learned pilot and has OCR/domain shift; bounded train OCR is optional only within these same64 pages and must be declared. It does not justify an accuracy claim before evaluation.

Model2Vec+LogisticRegression is a named real fallback only if the controller explicitly accepts inability to prepare LightGBM. No compatible pretrained layout head was found; topic classifiers, nearest label vectors, hashing and regex cannot be called the learned arbitrator. If acquisition/fitting fails, keep flags off, expose unavailable/abstain, and report Step3 incomplete.

## V3 contract

Append `Proposal.reading_order_rank:int|None=None`, `Proposal.polygon:list|None=None`. Existing positional/JSON constructors remain valid. `serialize_proposal(p)` omits only the two new None-valued fields; replace cascaded Proposal serialization sites that otherwise alter legacy dictionaries.

`v3_features.normalize_paddle_box(raw,*,width,height,variant,proposal_id)->(Proposal|None,audit)` preserves current bbox/score/label behavior and retains actual public V3 feature pairing. Positive integer order n maps to zero-based n-1; missing/None/invalid stays None. No index or geometric-sort rank. Polygon is finite page-pixel xy, simple valid positive area with >=3 distinct points. Clip to page only when one valid polygon survives; invalid or multicomponent geometry is unavailable, not repaired by hull/buffer. S and featureless historical caches use legacy behavior. Public rectangle polygons are valid public output but are not advertised as raw segmentation masks.

Paddle stage output includes original public box records/extraction mapping and capability audit: model/backend when available, package versions, schema, count/missing/invalid reasons, shape mode. Actual backend may lack masks. No nominal model ID alone proves useful geometry. New cache namespace comes from source/config signatures; old caches are immutable.

Capture metadata independently of usage flags. Old featureless payload roundtrip stays dictionary-identical with newNone keys omitted; fresh measured-feature payloads retain actual evidence, and false-flag behavioral comparisons use canonical geometry/labels/lineage/ownership. Do not remove non-None evidence to force equality. Audit/raw output must serialize with allow_nan=False: numpy arrays/scalars normalize to JSON types and invalid NaN/Inf become explicitly tagged/string/null values with reasons. Task1 may touch fusion/attribution only to replace Proposal serialization sites.

`v3_geometry.proposal_shape`, `proposal_line_coverage`, `protected_overlap` accept explicit use_v3_polygon flag; only eligible Paddle V3 measured polygons change ownership/protection. Detection bbox IoU and final box evaluation stay unchanged. Protected overlap denominator remains min(candidate area,protected shape area); thresholds remain unchanged. Apply the same helper in geometry_refine when combined Phase1 geometry is selected. Any geometry change clears stale polygon unless provenance explicitly supports a new derived shape. Preserve rank only while region identity remains.

`reading_order.build_reading_graph(proposals,lines,cfg)->dict` and `graph_neighbor(region,orphan_lines,graph,lines,confirmed)->dict` provide pure page-local adjacency evidence. Only unique adjacent text/body anchors in the same column and consistent top/bottom direction may support paragraph-boundary recovery. Duplicate/missing ranks, ambiguous recipient, cross-column adjacency, page-wide bridge, incompatible font/role, intervening visual/owner => legacy abstain. Graph evidence can relax only the old first-line left-margin check; horizontal containment, small gap, semantic gate, one edit per neighbor, complete old ownership and foreign/protected checks remain. No rank for OCR lines is invented.

## Semantic artifact and decision contract

Prepare isolated workspace Python target/venv containing base model2vec and LightGBM; do not change global torch/transformers. No model2vec distill/train extras. Resolve/pin package versions before installation and record hashes/versions. Resolve an actual full Hub model commit SHA then fetch only required potion8M StaticModel files at that revision into workspace cache; save SHA256. English256D embedding is approximately31MB including tokenizer; no duplicate ONNX or new Transformer weights. Runtime loads local directory offline, with no invented local_files_only keyword. Primary sources: [StaticModel source](https://raw.githubusercontent.com/MinishLab/model2vec/main/model2vec/model.py), [model files](https://huggingface.co/minishlab/potion-base-8M/tree/main), [LightGBM classifier](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMClassifier.html).

Acquire DocLayNet-v1.2/default/train rows through [official /rows API](https://huggingface.co/docs/dataset-viewer/rows), never full parquet. Prospectively use16 evenly spaced offset blocks of4 rows (64 max) across official train row count; deduplicate row_idx/page_hash. Query dataset repo SHA before and after fetch; fail if it changes. /rows does not promise revision pinning: store exact raw response bytes+SHA256, repo/config/split, timestamps, observed SHAs, source page/document metadata and `api_revision_verified:false` unless genuinely verified. This immutable local payload is corpus identity; do not claim it is git-pinned data. Cap each response25MB and total row payload100MB; no automatic broader retry/download. Optional image acquisition within these64 pages is capped64 images/100MB and uses separate sample namespace, never canonical valid/test directories. Preserve pdf_cells omitted by existing COCO extractor.

Group by original_filename; deterministic SHA256 ordering of document identities selects approximately25% calibration groups, at least one calibration and one fit document. If fewer than two source documents or usable classes/rows remain, fitting fails explicitly; do not split lines from one page/document across roles. Record actual group/page counts, not an assumed48/16 split. Store page_hash and qualified train row_idx; assert no valid/test membership or content collision. Unsupported classes abstain.

Artifacts live under `scratch/cascaded_phase2/semantic_artifacts/<fingerprint>/`: corpus.jsonl, split_manifest.json, feature_schema.json, embedding_manifest.json, classifier.txt, calibration.json, model_manifest.json, train_metrics.json. Retain native model and JSON metadata, not opaque unaudited pickle. Manifest records source/raw/OCR hashes, actual training/calibration IDs and documents, class mapping/support, feature version, model/package revision and calibration status.

`semantic_features.region_features(label-free inputs)->np.ndarray` concatenates rec-weighted256D line embeddings and normalized geometry/count/case/digit/punctuation/prefix features. Exclude GT font attributes, GT order and unavailable nearest-nontext features from this pilot. Runtime only uses all nonempty OCR lines with measured rec_score>=.75; otherwise abstain. PDF-cell training uses uniform cell weights with text_source=pdf_cells provenance, never fabricated rec_score. Declare the cell-vs-OCR shift. No candidate GT label enters features; detector score participates only in arbitration.

`SemanticArbitrator.from_artifact(path)` loads once per Experiment; `predict(label,lines,page_lines,bbox,width,height)->dict` returns available, probabilities keyed by exact literal labels, supported_classes, abstain_reason, calibration_status, feature/model fingerprints and measured CPU time. Unavailable and low-confidence abstain are distinct. Cache per-line embeddings page-locally. Validate finite dimensions/hashes/classes/calibration before exposing probabilities. Reject image/chart for text-only evidence. Class support minimum is five fit and three calibration examples; otherwise abstain for that class. If calibration has <30 total examples or <2 supported classes, mark uncalibrated and prohibit direct conflict commit.

Fit LightGBM on fit groups only, deterministic seed0 and bounded CPU threads; calibrate probabilities with one scalar temperature on held-out groups only, record reliability/logloss/Brier and supported-class coverage. Keep .60 semantic gate; joint=.55*detector+.45*calibratedP(label), winner joint>=.65 and margin>=.15. These are DOCX initial thresholds, not guarantees. Q remains .45coverage-.30split+.25semantic and replacement requires >KEEP+.10.

Thread an explicit optional `semantic=None` argument through prepare_layout, quality, attribution candidate/partition/finish helpers and ABSORB, preserving all old call signatures. No global monkeypatch/state. Arbitration flag controls pre-MinerU textual conflict and weak/small recovery; quality flag independently controls attribution semantic checks and Q. Missing artifact/dependency leaves legacy fallback and structured unavailable reason; flagsFalse load no learned dependencies.

Direct conflict commit is restricted to one-to-one textual conflict with identical eligible OCR ownership and all existing geometry safety checks; preserve PP geometry/lineage and measured detector score. No multi-fallback replacement, stealing/duplicate lines, no unsupported roles. Ambiguity goes to the original MinerU target. Learned confidence never overrides bisection/cross-column/foreign ink/protected overlap/completeness/one-edit guards.

## Verification and success criteria

Tester proves false-flag baseline identity for all40 variant-page observations against immutable saved results and unchanged input hashes; adds meaningful RED/GREEN contract, spatial safety, learned-artifact failure and real-feature tests. One fixed valid V3 page first establishes actual adapter feature capability, then at most the fixed20 valid V3 pages into a fresh cache if capability passes. No GPU model is loaded merely to prove unit contracts.

After the fixed20 capture, extend the validation sample with 30 distinct valid pages in a separate manifest. Use the local validation shard if available. Keep a distinct matched analysis for the original 20, and report a 50-page matched analysis only where all required inputs are available.

Run valid ablations: baseline, V3 polygon-only, order-only, both; semantic arbitration-only, Q-only, both; combined available features. S is fallback control. Report strictF1@.50/.75 and TP/FP/FN/per-class, ownership/accounting, targets changed, abstain/capability coverage, requested vs invoked vs avoided MinerU calls, semantic CPU cost. Historical featureless cache is not actual V3 evidence. Reused MinerU responses with changed targets/crops are fixed-response counterfactual only; no end-to-end latency claim or fresh inference claim. Fresh unavailable responses retain fallback and are counted as unresolved. No default flag promotion based on small pilot.

Completion requires concrete learned artifact, measured V3 capability and honest ablation evidence, or an explicit blocked/incomplete account identifying unavailable pieces. Installing packages or passing synthetic tests alone is not Step3 completion.
